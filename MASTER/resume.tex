\section{Extra: Especificaciones técnicas del notebook}

\begin{itemize}
    \item CPU: Intel Core i7/i9 o AMD Ryzen 7/9.
    \item RAM: 16 GB mínimo, preferiblemente 32 GB.
    \item Almacenamiento: SSD de al menos 512 GB.
    \item GPU: Integrada
\end{itemize}

Se necesitan un procesador con una gran cantidad de núcleos para hacer simulaciones de ANSYS de manera local. Además, se requiere suficiente memoria RAM para hacer simulaciones detalladas. Por la naturaleza de las simulaciones, no es necesario contar con una GPU dedicada.
